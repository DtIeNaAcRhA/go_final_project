go_final_project - мой итоговый проект курса по GO backend разработки.

В данном проекте реализовано веб приложение - планировщик задач. 


Мной реализованы: 
1. Аутентификация пользователя, идентификации пользователя. 
2. Добавление, редактирование, поиск, удаление задачи, выполнение задачи (перенос даты на следующую, если установлено правило повторения задачи, или удаление).
3. Логика переноса даты задачи на следующую при указании правила повторения задачи. 
4. Получение списка задачи отсортированного по дате без параметров поиска и с ними.


Задание выполнено со всеми усложнениями. 

Программа использует следующие переменные окружения:
        1. TODO_DBFILE - файл БД.
        Для запуска программы я использовала - scheduler.db, 
        для запуска тестов необходимо использовать ../scheduler.db или запускать тесты в терминале, где не установлена данная переменная окружения, 
        тогда значение будет взято по умолчанию из go_final_project/tests/settings.go.
        
        2. TODO_PORT - порт. 
        Для запуска программы я использовала - 7540

        3. TODO_PASSWORD - пароль для аутентификации.
        Для запуска программы я использовала - 123qwe

        4. TODO_SECRET_KEY - секретный ключ для формирования токена.
        Для запуска программы я использовала - my_secret_key

По желанию все значения переменных окружений можно заменить. 

Чтобы запустить программу можно воспользоваться 
командой go run main.go 
        Перед запуском данной команды можно определить переменные окружения, 
        если они не установлены, будут использоваться значения по умолчанию 

или воспользоваться докер образом. 
        Для этого необходимо выполнить следующие команды в терминале: 
        1. docker-compose build  сборка образа
        2. docker-compose up  запуск обрааза 
        В таком случае все переменные окружения установлены в файле .env 
        По желанию все значения переменных окружений можно заменить.
